# Security

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/jasonsdevspace/inventory-reservations/security/advisories/new)
rather than in a public issue.

## What is in scope

This is a demonstration project, not a deployed service. Reports about the code are welcome,
especially anything that lets one merchant read or change another merchant's data, gets past the
API key check, or works around the restricted database role the service runs as.
